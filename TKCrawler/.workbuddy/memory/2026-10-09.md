## SaaS 化方向讨论：cookie 池归属
- 用户问 SaaS 化后 cookie 池由用户提供还是平台自维护。结论：BYOA（用户自带账号授权）为主。
- 理由：目标客户（跨境卖家/企业）自有账号资产；合规责任在用户侧；账号成本不进 COGS；现有 pool_add_account → cookie池 → lease → health_checker 链路即 BYOA 自助导入架构。
- 自维护池仅在"数据 API 公司"定位下成立，需对抗 TikTok Research API 官方正规军，暂不考虑。
- 关键工程坑：cookie 过期体验 → 需补账号健康度仪表盘 + 失效前主动提醒 + 套餐按账号数阶梯（复用 daily_quota 机制）。
- 远期混合：公开数据平台自采（无需账号）+ 账号级数据 BYOA。
