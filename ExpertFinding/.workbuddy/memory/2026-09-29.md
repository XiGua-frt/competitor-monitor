
## 浏览器会话提取 + 自建爬虫链路验证（全部打通）
- 从用户 Chrome v153 Default profile 提取 TikTok 完整登录态（35 条 cookie，sessionid 至 2027-01）。
- Chrome 130+ 解密关键坑：Cookies DB meta.version>=24 时明文前 32 字节是 SHA256(domain)，解密后必须去掉；经典方案 v10+AES-128-CBC+PBKDF2(saltysalt,1003) 仍有效。
- **搜索 API /api/search/general/full/ 无需 X-Bogus 签名**：会话 cookie + curl_cffi chrome131 指纹 + 本机代理出口（系统代理 127.0.0.1:7892）→ status_code=0 实数据。签名模块降级为后备方案，Phase 1 不阻塞。
- 三条失败链路确认：profile SSR 带 WAF JS 挑战（会话也拦）；匿名 API 空 body；旧版 user/detail 已废。
- 频率风控：搜索 API 触发 IP 级软冷却（200 空 body 非 429），冷却数分钟起，需退避+批量设计。
- 排障教训：出口路径有三层（沙箱代理 64724 / 直连 / 用户本机代理 7892），WAF 结果完全取决于走哪个出口；诊断 WAF 前先确认出口。
